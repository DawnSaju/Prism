# Prism App

## Personal RAG Integrated Semantic Multimodal

### Challenge Track
* Qdrant
* Gemini

### Short Description
PRISM (Personal RAG Integrated Semantic Multimodal) is an AI powered platform that integrates documents, code, and images. It offers semantic search with Qdrant, RAG chat powered by Gemini, and smart recommendations to gain insights across content types.

### Long Description
PRISM is designed to make research and study more efficient by integrating different types of content documents, code files, and images into a single searchable platform. Students and researchers can quickly find relevant papers, code snippets, and visual materials using advanced semantic search powered by Qdrant 768 dimensional vectors and Google Gemini AI. The platform also offers a dual mode chat interface that answers questions based on content context, helping users understand complex topics faster. PRISM generates descriptive embeddings for all files, provides smart recommendations, and visualizes relationships through an interactive vector graph, allowing users to discover hidden connections between their materials. With a clean, responsive interface, realtime analytics, and secure authentication, PRISM turns research and study workflows into a connected, intelligent knowledge hub, making learning and discovery faster, smarter, and more organized.
